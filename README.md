# 🚪 Garage Door Opener  
A Raspberry Pi-powered garage door opener with **secure authentication** using a **4x4 checkbox pattern**. Built with **Python, Flask, and GPIO**.

## 🔥 Features  
- ✅ Secure authentication using a **4x4 checkbox grid**  
- ✅ Remote access via **Flask web interface**  
- ✅ Toggle garage door status (`Open` / `Closed`)  
- ✅ Built with **Raspberry Pi + Relay Module**  
- ✅ **Error handling** for incorrect patterns  

---

## 🛠️ Hardware Requirements  
- **Raspberry Pi Zero W**  
- **Relay Module** (to control the garage door)  
- **Jumper Wires** (for connections)  
- **Wi-Fi Module** (if using Raspberry Pi Zero)
